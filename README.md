# EbookClassics — fichiers ebooks

Ce dépôt héberge les fichiers téléchargeables (EPUB, PDF, TXT, HTML) du site **EbookClassics**, qui propose des classiques littéraires du domaine public à 0,99 € dans plusieurs langues.

## Sources

Tous les textes proviennent de sources du domaine public :
- [Project Gutenberg](https://www.gutenberg.org)
- [Wikisource](https://wikisource.org)
- [Standard Ebooks](https://standardebooks.org)

Chaque édition n'est publiée qu'après vérification du statut domaine public (auteur **et** traducteur le cas échéant) aux États-Unis et dans l'Union européenne.

## Convention de nommage

```
<slug>/<slug>.<ext>       -> édition anglaise
<slug>/<slug>-<iso>.<ext> -> autres langues (ex. -fr pour le français)
```

Formats disponibles : `epub`, `pdf`, `txt`, `html`.
